单文件模式
📐
Shapefile 转 GeoJSON
使用 ogr2ogr 将 Shapefile 转换为 GeoJSON 格式
当前为单文件模式：处理单个输入文件
参数设置
input * file_path

输入 Shapefile 路径（.shp）

pattern * pattern

文件匹配模式，如 *.shp、*.tif

output * file_path

输出 GeoJSON 路径

批量模式说明
  • 系统会遍历指定目录下所有匹配 *.shp 的文件
  • 对每个文件执行 ogr2ogr 转换命令
  • 输出文件名自动使用 {原始文件名}.json 格式
  • 外层使用 for 循环 + && 链，失败时中断
脚本预览
单文件命令
@echo off
ogr2ogr -f "GeoJSON" "C:\GISData\roads.json" "C:\GISData\roads.shp"
批量执行摘要
遍历目录 C:\GISData
匹配模式 *.shp
输出目录 C:\GISData
预计处理文件数 3 个
