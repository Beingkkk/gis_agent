🔗 双入口设计

🖼️ Electron 桌面应用（主推荐）
React + TypeScript + Vite 渲染器，FastAPI 后端作为子进程运行。支持文件对话框获取绝对路径。三 TAB 架构：Discovery / Q&A / Exec。通过 WebSocket 实现流式 Q&A 和实时执行日志。
⌨️ CLI 命令行 REPL
命令行交互式 REPL，适用于无 GUI 环境。支持斜杠命令、Y/N 确认、状态机全流程。与桌面应用共享同一套 core / llm / templates 业务逻辑。

🔀 三 TAB 关键交互流

1
DiscoveryTab 意图匹配
用户输入自然语言 → POST /session/{id}/intent → 两阶段匹配（关键词粗筛 + LLM 精排）→ 高置信度直接 PARAM_COLLECT，低置信度展示候选模板
2
QATab 知识问答
用户提问 → POST /session/{id}/chat → 代码层分支：locked_template 存在时走模板知识问答，不存在时走 GIS 专家问答 → WS /ws/chat 流式返回
3
ExecTab 脚本执行
用户确认 → WS /ws/execute 实时日志 → 成功返回 IDLE / 失败进入 ERROR_RECOVERY → 一键诊断导航到 QATab
4
ExecTab 工作空间切换
用户点击浏览选择目录 → POST /session/{id}/workspace → 保留当前会话状态，仅更新默认 cwd 和输出基准目录 → ParamValidator 和 TemplateEngine 重新创建

🚫 安全红线 (Security Principles)

P1 — 模板化命令，杜绝幻觉
所有 GDAL 命令必须通过 Jinja2 模板渲染生成，严禁动态字符串拼接。LLM 只负责选择模板 ID 和填充参数。
P2 — 先展后行
任何脚本必须向用户完整展示内容，获得明确确认后才可执行。WebSocket 执行过程实时可见。
P3 — 最小权限
默认输出到工作空间，输出文件自动加时间戳防覆盖。路径经规范化后使用。workspace 是默认操作目录，不是安全边界。绝对路径直接放行。
P4 — 模板知识唯一
用法指导类知识仅来源于 J2 模板元数据，基硎概念类回答由 LLM 参数知识提供，禁止调用外部 API。
P5 — 最小依赖
生产依赖仅锁定 anthropic、jinja2 两个库。FastAPI / uvicorn 为 UI 可选 dev 依赖。降低供应链攻击面。
