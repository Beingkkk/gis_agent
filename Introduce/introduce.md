# GIS Agent 产品介绍视频 — 文案脚本

## 视频规格

- **时长**: 50s
- **分辨率**: 1920×1080
- **风格**: 科技感
- **品牌色**: 主蓝 `#3b82f6`，辅青 `#06b6d4`，背景深 `#0f172a`

## 场景时间线

### Scene 0 — 品牌底栏（Persistent，0-50s）

- 顶部：GIS Agent Logo + 品牌名（固定）
- 底部：进度轨道 + 当前场景指示器
- 背景：深色科技网格 + 微弱粒子流动

### Scene 1 — 开场（0-5s）

**文案**:
- 主标题：GIS Agent
- 副标题：自然语言 · GIS 数据处理助手
- 标签：一句话，搞定复杂 GDAL 命令

**视觉**:
- Logo 中心放大入场
- 标题逐字出现（科技感打字效果）
- 背景：蓝色渐变光晕扩散

### Scene 2 — 痛点 → 方案（5-10s）

**文案**:
- 痛点：GDAL 命令复杂难记？
- 方案：说一句话，系统自动匹配工具

**视觉**:
- 左侧：命令行代码块（混乱）
- 右侧：自然语言输入框（清晰）
- 中间：箭头转换动画

### Scene 3 — 核心工作流（10-28s，18s）

展示完整 "shp 转 geojson" 流程，分 5 个节拍：

**节拍 1 — 启动与筛选（10-14s）**
- 截图：1.软件启动初始 + 4.意图识别筛选（shp转geojson）
- 文案：输入需求，智能匹配最佳模板

**节拍 2 — 参数问答（14-18s）**
- 截图：5.基于模板问答
- 文案：交互式问答，自动提取参数

**节拍 3 — 指令生成（18-22s）**
- 截图：6.模板内填入数据生成指令
- 文案：一键生成完整 GDAL 脚本
- 示例数据：roads.shp → roads.geojson

**节拍 4 — 错误诊断（22-25s）**
- 截图：7.指令执行错误一键诊断修复
- 文案：执行异常？AI 自动诊断修复

**节拍 5 — 执行成功（25-28s）**
- 截图：8.指令执行成功
- 文案：执行成功，结果一目了然

### Scene 4 — 模板生成器（28-40s，12s）

展示从 GDAL 文档到可用模板的完整链路，分 4 个节拍：

**节拍 1 — 文档导入（28-31s）**
- 截图：9.工具文档导入（html或md）
- 文案：导入 GDAL 官方文档

**节拍 2 — 智能生成（31-34s）**
- 截图：10.模板生成结果
- 文案：AI 自动生成 Jinja2 模板

**节拍 3 — 编辑审核（34-37s）**
- 截图：11.模板编辑 + 12.模板审核成功保存
- 文案：人工审核编辑，安全校验保存

**节拍 4 — 即时生效（37-40s）**
- 截图：13.模板库查找验证
- 文案：保存即生效，模板库实时更新

### Scene 5 — 扩展能力（40-45s，5s）

**文案**（三个卡片轮播）：
1. 脚本导出 — 一键导出为 .bat / .sh，离线复用
2. 批量指令 — 多步骤流水线编排，参数自动传递
3. 环境配置 — 自动发现 Python 环境，零配置启动

**视觉**: 三卡片横向滑入

### Scene 6 — 结尾（45-50s，5s）

**文案**:
- Slogan：GIS Agent — 让数据处理更简单
- CTA：立即体验

**视觉**:
- Logo + 品牌名居中
- 底部：版权信息
- 背景：粒子汇聚成 Logo 形状
