# 需求变更清单：v4 三 TAB 设计

> 对比基线：spec.md v1.1.0 + plan-ux.md v1.5.0
> 目标：确认需要调整的 spec 和 plan 范围

---

## 一、当前基线 vs 新设计的核心差异

| 维度 | 当前基线 | v4 新设计 |
|------|---------|----------|
| **整体布局** | 三栏：模板列表(300px) + 聊天区(flex-1) + 参数面板(520px) | **两栏**：主交互区(flex-1) + 参数面板(580px) |
| **模板发现** | 左栏常驻模板列表 + 聊天区问答匹配 | **TAB 1「模板识别」**：统一入口，不累积历史 |
| **知识问答** | 聊天区混合承载（意图匹配 + 知识问答） | **TAB 2「GIS 问答」**：独立区域，累积历史，可清空 |
| **脚本预览** | 聊天区显示代码块（SCRIPT_PREVIEW 状态） | **TAB 3「脚本执行」**：独立编辑器，可修改命令，四种执行状态 |
| **错误恢复** | ERROR_RECOVERY 状态在聊天区显示诊断 | 执行失败在脚本执行 TAB 展示，支持**一键诊断**自动跳转 GIS 问答 |
| **状态机映射** | 6 状态映射到三栏的不同区域 | 6 状态映射到三 TAB 的不同视图 |

## 二、Spec（spec.md）变更分析

### 2.1 无需变更的需求项

以下需求在新设计下仍然完全适用，无需调整：

| ID | 需求 | 说明 |
|----|------|------|
| F1 | 文档问答 | GIS 问答 TAB 承载，功能不变 |
| F2 | 意图→模板映射 | 模板识别 TAB 承载，功能不变 |
| F3 | 参数抽取与追问 | 右侧面板 ParamForm 承载，功能不变 |
| F4 | 脚本生成 | 后端渲染逻辑不变 |
| F6 | 安全与隔离 | 规则不变 |
| F7 | 工作空间管理 | 机制不变 |
| F8 | 会话内记忆 | GIS 问答 TAB 累积历史，本质仍是会话内记忆 |
| F9 | 多步任务 | Pipeline 功能不受影响 |
| F11 | 任务入口手册 | Agents.md 加载机制不变 |

### 2.2 需要扩展的需求项

#### F5 — 用户确认与执行（Must）

**当前描述**：向用户完整展示脚本内容，要求明确确认（Y/N）后执行。

**需要扩展**：
- 在 Electron UI 下，"展示脚本"从聊天区的代码块升级为**独立的脚本执行 TAB**
- 用户可以在执行前**直接编辑生成的 bash 命令**
- 确认执行后，在同一 TAB 内展示执行进度和结果

**建议变更**：在 F5 的"关键设计点"中增加：
> UI 模式下提供命令编辑器，允许用户在执行前审查和修改生成的命令；执行过程和结果在同一视图内展示，无需切换页面。

#### F10 — 错误诊断（Should）

**当前描述**：执行失败时，捕获 GDAL 错误信息并给出简单修复建议。

**需要扩展**：
- 新增**一键诊断**交互：系统自动收集模板信息、执行命令、错误输出，打包发送给 LLM 进行诊断
- 诊断结果通过**GIS 问答 TAB**呈现，支持多轮追问
- 一键诊断自动清空 GIS 问答历史，确保诊断上下文独立

**建议变更**：在 F10 描述后增加：
> UI 模式下支持"一键诊断"：执行失败时，用户点击按钮即可将模板上下文、执行命令和错误输出自动发送给 LLM 诊断，诊断结果在独立的问答区域呈现，不影响其他任务流程。

### 2.3 建议新增的需求项

以下功能在 spec 中没有独立条目，但新设计使其成为一级功能：

| 建议 ID | 需求名称 | 优先级 | 说明 | 关联原型 |
|---------|---------|--------|------|---------|
| **F14** | **命令编辑** | Must | 脚本执行前，用户在脚本执行 TAB 中可直接编辑生成的 bash 命令，修改后的命令经安全校验后执行 | v4 脚本执行 TAB - 命令预览态 |
| **F15** | **一键诊断** | Should | 执行失败时，一键收集模板信息、执行命令、stdout/stderr，自动发送到 GIS 问答 TAB 进行 LLM 诊断；诊断前自动清空问答历史 | v4 一键诊断按钮 + 自动提问 |

### 2.4 Won't 列表确认

当前 Won't 中有：
> - 原生桌面 GUI 应用（如 Electron 等独立可执行程序）

**注意**：这个 Won't 项是在 v1.0.0 中定义的，v1.1.0 已经将其调整为支持浏览器 UI。而我们现在实际上已经用 Electron 实现了。这个 Won't 项已经过时，应该在 v1.2.0 中移除或调整。

## 三、Plan（plan-ux.md）变更分析

### 3.1 需要更新的设计决策

#### DC-UX-02: CLI 状态机映射为 UI 状态

**当前映射**（需要更新）：

| SessionState | 当前 UI 表现 | **新 UI 表现** |
|-------------|-------------|---------------|
| `IDLE` | 探索态：左栏浏览卡片，聊天自由问答 | 模板识别 TAB：卡片网格 |
| `INTENT_CONFIRM` | 聊天区显示候选卡片 | 模板识别 TAB：候选列表 |
| `PARAM_COLLECT` | 右栏展开表单 | **模板识别 TAB + 右侧面板表单** |
| `SCRIPT_PREVIEW` | 聊天区显示脚本代码块 | **脚本执行 TAB：命令预览态** |
| `EXECUTING` | 脚本区变为进度状态 | **脚本执行 TAB：执行中态** |
| `ERROR_RECOVERY` | 聊天区显示诊断结果 | **脚本执行 TAB：失败态** → 可一键诊断到 GIS 问答 TAB |

**关键变更**：PARAM_COLLECT / SCRIPT_PREVIEW / EXECUTING / ERROR_RECOVERY 的 UI 承载区域全部改变。

#### §4.1 单任务流程图

当前流程图需要重绘：
- "用户点击执行 → WS /ws/execute 连接" 之后，不再是"实时推送执行日志（EXECUTING → IDLE）"
- 而是：执行完成后在脚本执行 TAB 展示成功/失败结果
- 失败后增加"一键诊断"分支

#### §5 前端组件结构

需要新增/重命名的组件：

```
components/
  ├── Layout.tsx                    # 两栏布局（去掉左栏模板列表）
  ├── TopBar.tsx
  ├── TabBar.tsx                    # 新增：三 TAB 切换栏
  ├── DiscoveryTab.tsx              # 新增：模板识别 TAB（搜索+卡片网格+候选结果）
  ├── QATab.tsx                     # 新增：GIS 问答 TAB（聊天流+输入+清空）
  ├── ExecTab.tsx                   # 新增：脚本执行 TAB（四种状态）
  ├── CmdEditor.tsx                 # 新增：命令编辑器
  ├── ExecStatusPanel.tsx           # 新增：执行状态面板（成功/失败）
  ├── DetailPanel.tsx               # 保留：右侧面板（模板详情/参数表单）
  ├── ParamForm.tsx                 # 已更新：分组折叠+水平布局
  └── ...
```

### 3.2 需要新增的设计决策

| 决策 ID | 名称 | 内容概要 |
|---------|------|---------|
| **DC-UX-10** | **双 TAB 分离：模板识别 vs GIS 问答** | 将模板搜索匹配和知识问答从混合的聊天区分离为两个独立 TAB。模板识别 TAB 不累积历史，每次输入都是独立的匹配请求；GIS 问答 TAB 累积多轮历史，有清空按钮。 |
| **DC-UX-11** | **脚本执行 TAB：命令编辑 + 执行 + 结果** | 确认参数后自动切换到脚本执行 TAB。该 TAB 包含：命令编辑器（可修改 bash）、执行按钮、实时日志、成功/失败结果展示。四种状态：预览 → 执行中 → 成功/失败。 |
| **DC-UX-12** | **一键诊断：执行错误自动问答** | 执行失败时，用户点击"一键诊断"按钮，系统自动收集模板信息、执行命令、stdout/stderr，切换到 GIS 问答 TAB，清空历史，自动发送诊断消息给 LLM。诊断结果支持多轮追问。 |
| **DC-UX-13** | **布局从三栏变为两栏+三TAB** | 移除独立的模板列表侧边栏（300px），将其功能并入模板识别 TAB。主交互区改为 flex-1 自适应。参数面板扩宽至 580px。 |

## 五、变更工作量评估

### 前端（主要工作量）

| 模块 | 工作量 | 说明 |
|------|--------|------|
| Layout 重构 | 中 | 三栏 → 两栏，移除 TemplateCardList 左栏 |
| TabBar + Tab 切换 | 小 | 新组件，逻辑简单 |
| DiscoveryTab | 中 | 整合原有的 TemplateCardList + ChatArea 的意图匹配 |
| QATab | 中 | 类似原 ChatArea，但独立为 TAB，增加清空功能 |
| ExecTab（核心） | **大** | 四种状态（预览/执行中/成功/失败），命令编辑器，一键诊断 |
| DetailPanel / ParamForm | 小 | 已更新，只需调宽度 |
| useSession hook | 中 | 增加当前 activeTab 状态 |

### 后端（工作量较小）

| 模块 | 工作量 | 说明 |
|------|--------|------|
| API 路由 | 小 | 可能新增一个诊断触发接口，或复用现有问答接口 |
| 一键诊断 Prompt | 中 | 设计诊断用系统 Prompt，整合模板信息+命令+错误输出 |
| 状态机 | ❌ 无 | core/ 状态机不变 |
